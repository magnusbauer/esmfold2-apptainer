# Attribution

This repository is an Apptainer packaging layer for Biohub ESMFold2. It is not
the upstream ESMFold2 project.

Upstream projects and artifacts:

- ESM code and documentation: https://github.com/Biohub/esm
- ESMFold2 model weights: https://huggingface.co/biohub/ESMFold2
- ESMC-6B model weights: https://huggingface.co/biohub/ESMC-6B
- Biohub ESM overview: https://biohub.ai/esm/protein

The upstream `esm` README states that the ESMC, ESMFold2, and related model
artifacts are available under the MIT license. Check the upstream repositories
and model cards for the current license and usage terms before redistributing
derived images.

If you use ESMFold2, ESMC, or the ESM software in research, cite the upstream
Biohub ESMFold2/ESMC work:

Candido et al. "Language Modeling Materializes a World Model of Protein
Biology." Preprint, 2026. https://biohub.ai/papers/esm_protein.pdf

Also cite the upstream ESM software record when appropriate:

EvolutionaryScale Team. "evolutionaryscale/esm." Zenodo, 2024.
https://doi.org/10.5281/zenodo.14219303
